# Pallapu Dileep Kumar — Netflix Portfolio

A cinematic Netflix-inspired developer portfolio built with React, Tailwind CSS and GSAP.

## Included
- Pallapu Dileep Kumar profile and professional photo
- Education timeline
- Internship / work-experience timeline
- Certificate and achievement vault with certificate previews
- Downloadable certificate archive
- Featured software, AI/ML and full-stack projects
- Skills, expertise, contact and social links

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Configured for GitHub Pages project deployment at:
